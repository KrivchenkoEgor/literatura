# Физика 7 класс — база знаний для ИИ-репетитора

## Что это

Бумажный учебник физики 7 класса (Перышкин, Иванов, 2026, 239 страниц) прошёл через OCR и ручную вычитку. На выходе — набор Markdown-файлов, по которым ИИ-агент ищет материал через grep и отвечает ученику.

Плюс отдельный сборник из 50 задач к экзамену (не из учебника).

## Зачем

Репетитор не может запомнить весь учебник. Но может быстро найти нужный параграф по ключевым словам и объяснить его своими словами — или проверить, что его ответ совпадает с эталоном из `ответы/`.

## Формат файлов

Каждый MD-файл начинается с шапки:

```markdown
# §18. Прямолинейное равноускоренное движение. Ускорение

> Источник: Физика. 7 класс (Перышкин, Иванов, 2026), стр. 57–60
> Ключевые слова: ускорение, равноускоренное движение, скорость, время
```

Дальше — текст учебника, формулы обычными символами (никакого LaTeX):

```
a = (v − v₀)/t
E_к = mv²/2
F_тяж = m·g
```

Рисунки встроены как изображения с подписями. Таблицы восстановлены по сканам.

## Как пользоваться

Для ИИ-репетитора: положи папку `literatura/` рядом с агентом, добавь `Тестовый_AGENTS.md` в системный промпт. Агент сможет искать по ключевым словам, читать разделы и сверяться с эталонными ответами.

Для человека: просто открой `учебник/00-oglavlenie.md` — там вся навигация по темам.
